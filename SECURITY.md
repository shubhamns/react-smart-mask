# Security

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open public issues for security problems.

Email the maintainer privately with:

- A description of the issue
- Steps to reproduce
- Impact assessment, if known

You will receive a response with next steps. Please allow reasonable time for a fix before public disclosure.

## Secrets

Never commit `.env`, API keys, tokens, or credentials. Use `.env.example` as a template only.
